# テストマトリクスを設計する

## 手順

1. ユーザーが指定したファイルまたはフォルダを読む。対象が指定されていない、または候補が複数あって意図を判定できない場合は、作成前に対象パスを確認する。
2. 入力パラメータ、条件分岐、境界、不正値、戻り値、副作用を根拠として因子と水準を決める。仕様書がある場合はコードとの差異も確認する。
3. 有効な水準の全ペアが少なくとも1回現れるようにケースを選ぶ。単独で必要な境界・異常系はペアワイズケースとは別に追加する。
4. 各ケースの `expected` を具体化する。判定不能な場合だけ `要確認` とし、理由を `memo` に記載する。
5. 利用可能なスプレッドシート作成手段を使い、次の契約でExcelを作成する。
6. 保存後にワークブックを再読込して、シート、列、ケース件数、主要セルを検証する。

## 出力契約

- 保存先: `testcases/testcase_<class>_<method>.xlsx`
- ファイル名を一意に決められない場合はユーザーに確認する。
- シート `因子と水準`: `因子`, `水準1` 以降の可変列, `備考`
- シート `テストケース`: `ID`, 各因子列, `expected`, `memo`
- `ID` は `TC-001` からの一意な連番とする。
- JSONやテストコードは作成しない。

## 完了報告

保存先、因子数、ケース数、追加した異常系、`要確認` の有無を報告する。
